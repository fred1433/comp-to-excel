      Files

        Not shown here

        • Local-source demonstration; Microsoft tenant integration not demonstrated. The documents were read from a local folder.
        • Excel for Mac 16.113, not desktop Excel on a Windows 365 runner. This machine has no active Microsoft 365 subscription, so Excel runs in read-only mode: it opened and recalculated the file but could not save it. The delivered file is the written file, with the same SHA-256 as the one Excel recalculated. Its formulas carry blank cached values, which is also their correct value until the appraiser picks a building area; Excel recalculates on open.
        • No party to the sale was contacted. The deed image was not retrieved: the instrument number, the sale date (deed or recording date, not stated) and the current owner come from the county assessment record.
        • The grid is ours, built to stand in for a firm's model. Its adjustment convention is one of several in use.
        • Word reports, a review queue and multi-agent quality control are left out.
